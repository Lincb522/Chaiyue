### 找书

粘贴链接、扫二维码，或直接导入书源 JSON。搜书时会同时查多个书源，同名同作者的书只列一次。某个源断更了，可以从书里换源，不用回书架重新找。

### 读书

从「文件」打开 EPUB 或 TXT 就能读。TXT 可以按自己的目录规则分章。读长文时可以上下滚动，也可以像纸书一样卷页。字号和行距可以分开调，也能装自己的字体和阅读主题。

出门前可以只缓存接下来几章，也可以把整本书存下来，没网时接着读。

### 听书和看漫画

正文可以逐句朗读，睡前设个定时关闭。一次选中多个音频文件，柴阅会按文件名排好，每个文件就是一章。CBZ 和 PDF 漫画可以逐页翻，也可以竖着连读。

### 换手机

把书架、书签和书源导出成 ZIP，或备份到自己的 WebDAV。换机时导入备份；要把本地书一起带走，备份时勾选「本地书籍」。
